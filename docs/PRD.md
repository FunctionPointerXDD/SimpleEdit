# 유튜브 영상 편집기 MVP PRD (Go + Wails)

Sep 28, 2026 · @chansjeo

## 1. 개요

MVP의 목표는 하나입니다. **70대 운전 강사가 도움 없이 "유튜브 주소 입력 → 구간 자르기 → 영역 가리기 → MP4 저장"을 10분 안에 끝낼 수 있는지** 검증합니다.

| 항목 | 내용 |
| --- | --- |
| 대상 사용자 | 70대 교통 운전 강사 1명 (PC 기본 조작 가능, 영상 편집 경험 없음) |
| 사용 목적 | 강의용 도로 주행·사고 영상에서 필요한 부분만 잘라 번호판·얼굴을 가림 |
| 플랫폼 | Windows 10/11 데스크톱 (1차) |
| 기술 스택 | Go + Wails v2, 프론트엔드는 바닐라 JS 또는 Svelte, 외부 도구 yt-dlp · FFmpeg |
| MVP 기간 목표 | 동작하는 첫 빌드 1\~2주 |

검증 질문은 두 가지입니다. 기술적으로는 yt-dlp와 FFmpeg를 Wails 앱에 넣어 멈춤 없이 돌릴 수 있는지, 사용성 측면에서는 강사님이 설명서 없이 4단계를 끝낼 수 있는지 확인합니다.

## 2. 사용자 흐름

화면은 한 번에 한 단계만 보여주는 마법사 방식입니다. 각 화면 하단에는 "이전"과 "다음" 두 버튼만 둡니다.

&#91;embedded content: 사용자 흐름 · 4단계 마법사\]

3단계는 가릴 것이 없으면 건너뛸 수 있습니다. 앱을 켤 때 yt-dlp 업데이트 확인이 화면 뒤에서 자동으로 실행되며, 사용자에게는 보이지 않습니다.

## 3. 기능 요구사항

MVP 기능은 다섯 개입니다. 구간은 1개, 모자이크는 자른 구간 전체에 고정 영역으로만 적용합니다.

| ID | 기능 | 상세 | 완료 기준 |
| --- | --- | --- | --- |
| F1 | 영상 불러오기 | "붙여넣기" 버튼으로 클립보드 URL 입력. youtube.com/watch, youtu.be, shorts 주소를 검증. yt-dlp로 최대 1080p MP4 다운로드. 보조 버튼 "내 컴퓨터 영상 열기"로 로컬 MP4 선택 | 5분 길이 영상이 진행률 표시와 함께 받아지고 미리보기에서 재생됨 |
| F2 | 구간 자르기 | 영상 재생 중 "여기서 시작", "여기서 끝" 버튼으로 현재 재생 시각 기록. 0.1초 단위. 끝이 시작보다 앞이면 저장 불가 안내 | 저장된 파일의 길이가 선택 구간과 ±0.2초 이내 |
| F3 | 영역 가리기 | 영상 위 투명 캔버스에서 마우스 드래그로 사각형 지정, 최대 5개, 각 사각형 옆 "지우기" 버튼. 화면 좌표를 원본 해상도 좌표로 변환 | 저장 파일에서 지정 영역이 구간 전체 동안 모자이크됨 |
| F4 | MP4 저장 | H.264 + AAC MP4로 재인코딩. 파일명 `운전강의_YYYYMMDD_HHMM.mp4`, 위치 바탕화면. 진행률, 남은 시간, "취소" 버튼. 완료 후 "저장 폴더 열기" | 저장 파일이 Windows 기본 플레이어와 카카오톡 전송에서 재생됨 |
| F5 | 도구 자동 업데이트 | 앱 시작 시 `yt-dlp -U`를 백그라운드로 실행. 실패해도 앱 사용은 계속 가능 | 네트워크 차단 상태에서도 앱이 정상 시작됨 |

## 4. UI 요구사항

모든 화면은 "지금 무엇을 누르면 되는지"가 한눈에 보여야 합니다. 기준은 아래 여섯 가지입니다.

- 본문 글자는 18px 이상, 주요 버튼 글자는 22px 이상, 버튼 높이는 56px 이상으로 합니다.
- 모든 버튼에는 한글 문구를 씁니다. 아이콘만 있는 버튼은 두지 않습니다.
- 화면 상단에 "1 / 4 영상 불러오기" 형식으로 현재 단계를 항상 표시합니다.
- 창 크기는 1280×800 고정으로 시작하고, 최대화만 허용합니다.
- 오래 걸리는 작업(다운로드, 저장)에는 진행률 막대, 퍼센트, 남은 시간을 함께 표시합니다.
- 오류는 원인과 해야 할 일을 한 문장으로 안내합니다. 예: "영상을 받지 못했습니다. 인터넷 연결을 확인하고 다시 눌러 주세요."

## 5. 기술 설계

Go 백엔드가 yt-dlp와 FFmpeg를 프로세스로 실행하고, 프론트엔드는 Wails 바인딩 호출과 이벤트만 사용합니다.

&#91;embedded content: 구조 · 3계층\]

### 핵심 설계 결정

- **미리보기 영상 서빙:** WebView는 임의의 로컬 경로를 직접 열지 못합니다. `assetserver.Options`의 `Handler`에서 `/video/current` 요청을 받아 `http.ServeContent`로 작업 파일을 내보냅니다. Range 요청이 지원되므로 탐색이 끊기지 않습니다.
- **콘솔 창 숨김:** Windows에서 `exec.Cmd.SysProcAttr`에 `HideWindow: true`와 `CREATE_NO_WINDOW`(0x08000000)를 지정합니다. 빠뜨리면 검은 창이 번쫍여 사용자가 당황합니다.
- **진행률과 취소:** 모든 외부 실행은 `exec.CommandContext`로 만들고, stdout을 줄 단위로 읽어 `runtime.EventsEmit`으로 퍼센트를 보냅니다. 동시에 실행되는 작업은 한 개로 제한합니다.
- **좌표 변환:** 프론트는 화면 표시 크기 기준 사각형을 보내고, Go가 ffprobe로 얻은 원본 해상도 비율로 변환합니다. 폭과 높이는 짝수로 맞춥니다.
- **도구 위치:** yt-dlp.exe, ffmpeg.exe, ffprobe.exe를 실행 파일 옆 `bin/` 폴더에 둡니다. PATH에 의존하지 않습니다.

### 패키지 구조

```
main.go              // Wails 설정, AssetServer Handler 등록
app.go               // 바인딩 메서드
internal/tools/      // bin/ 경로 해석, 숨김 프로세스 생성
internal/download/   // yt-dlp 실행, 진행률 파싱, 업데이트
internal/media/      // ffprobe 정보 조회, ffmpeg 필터 문자열 생성
internal/job/        // 취소 가능한 단일 작업 관리
frontend/            // 마법사 화면, video + canvas
```

### 바인딩 API

| 메서드 | 입력 | 반환 | 이벤트 |
| --- | --- | --- | --- |
| `PasteURL()` | 없음 | 클립보드 문자열 | 없음 |
| `Download(url)` | 유튜브 주소 | `VideoInfo` | `download:progress` |
| `OpenLocal()` | 없음 (파일 대화상자) | `VideoInfo` | 없음 |
| `Export(req)` | `ExportRequest` | 저장 경로 | `export:progress` |
| `Cancel()` | 없음 | 없음 | 없음 |
| `OpenOutputFolder()` | 없음 | 없음 | 없음 |

`VideoInfo`는 미리보기 URL, 길이(초), 원본 폭·높이를 담습니다. `ExportRequest`는 시작·끝(초)과 화면 기준 사각형 목록, 화면 표시 크기를 담습니다.

### 외부 명령 기준안

다운로드 (최대 1080p, MP4로 병합):

```
yt-dlp --no-playlist --newline \
  -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[ext=mp4]/b" \
  --merge-output-format mp4 \
  --ffmpeg-location bin/ \
  --progress-template "download:%(progress._percent_str)s" \
  -o "<작업폴더>/source.%(ext)s" <URL>
```

자르기 + 사각형 1개 모자이크 (값은 Go가 정수로 계산해 채움):

```
ffmpeg -y -ss <시작> -i source.mp4 -t <길이> \
  -filter_complex "[0:v]split[base][m];[m]crop=W:H:X:Y,scale=W/16:H/16,scale=W:H:flags=neighbor[px];[base][px]overlay=X:Y[v]" \
  -map "[v]" -map 0:a? \
  -c:v libx264 -preset veryfast -crf 20 -c:a aac \
  -movflags +faststart -progress pipe:1 -nostats out.mp4
```

사각형이 여러 개면 `split`과 `overlay`를 개수만큼 이어 붙입니다. 진행률은 `-progress` 출력의 `out_time_us`를 구간 길이로 나눠 계산합니다. 가릴 영역이 없으면 `-filter_complex` 없이 같은 인코딩 옵션만 사용합니다.

## 6. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 응답성 | 다운로드와 저장 중에도 화면이 멈추지 않음. 진행률은 1초 이내 간격으로 갱신 |
| 성능 목표 | 1080p 1분 구간 저장이 일반 사무용 PC(i5급)에서 2분 이내 |
| 오류 처리 | 잘못된 주소, 네트워크 끊김, 디스크 공간 부족, 도구 실행 실패를 각각 쉬운 문장으로 안내하고 해당 단계에 머무름 |
| 로그 | `%LOCALAPPDATA%\운전영상편집기\logs\app.log`에 외부 명령과 stderr 기록. 지원 요청 시 이 파일만 받으면 원인 파악 가능 |
| 작업 파일 | 원본 영상은 `%LOCALAPPDATA%\운전영상편집기\work\`에 저장, 앱 시작 시 7일 지난 파일 삭제 |
| 배포 (MVP) | 설치 파일 없이 zip 하나: 실행 파일 + `bin/` 폴더. 바탕화면 바로가기는 수동 생성. WebView2 런타임이 없으면 Wails 기본 안내를 따름 |
| 대상 OS | Windows 10/11 64비트 |

## 7. 범위 제외 (MVP 이후)

아래 항목은 MVP 검증이 끝난 뒤 우선순위를 다시 정합니다.

- 여러 구간 자르기와 이어 붙이기
- 시간대별 모자이크, 움직이는 대상 추적, 번호판·얼굴 자동 인식
- MP4 외 형식(AVI, GIF, MP3 추출 등) 선택
- 설치 파일(NSIS), 바탕화면 바로가기 자동 생성, 코드 서명
- 하드웨어 인코딩(NVENC, QSV) 자동 선택
- macOS 지원, 다국어

## 8. 테스트 계획과 완료 기준

테스트는 세 단계로 진행하고, 앞 단계를 통과해야 다음 단계로 넘어갑니다.

### 1단계: 기술 검증 (UI 없이 Go CLI로)

- [ ] Go에서 yt-dlp를 숨김 창으로 실행하고 진행률 퍼센트를 줄 단위로 읽음
- [ ] ffprobe로 길이, 폭, 높이를 JSON으로 받아 구조체로 파싱
- [ ] 자르기만, 자르기 + 사각형 1개, 자르기 + 사각형 3개 명령이 모두 재생 가능한 MP4를 만듦
- [ ] `Cancel` 시 ffmpeg 프로세스가 종료되고 미완성 파일이 삭제됨

### 2단계: 기능 테스트 (Wails 앱)

- [ ] 일반 영상, Shorts, 비공개·삭제된 영상 주소 각각에서 기대한 동작 또는 안내가 나옴
- [ ] 미리보기에서 앞뒤로 탐색해도 멈춤 없이 재생됨
- [ ] 720p, 1080p, 세로 영상에서 사각형 위치가 저장 결과와 일치함
- [ ] 인터넷을 끊은 상태에서 앱 시작, 다운로드 실패 안내 확인
- [ ] 저장 파일이 Windows 기본 플레이어와 카카오톡 전송에서 재생됨

### 3단계: 사용성 테스트 (강사님 직접)

- [ ] 설명 없이 "이 영상에서 30초만 잘라 번호판을 가려 저장해 주세요" 과제 수행
- [ ] 옆에서 도움 없이 10분 안에 완료
- [ ] 막힌 화면과 망설인 버튼을 기록해 다음 빌드에 반영

**MVP 완료 기준:** 1·2단계 항목 전부 통과, 3단계 과제를 강사님이 도움 없이 두 번 연속 성공.
