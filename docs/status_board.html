우선 확인
  • 강사님 영상으로 사람이 라벨링한 검증 세트를 만들어 얼굴 놓침 측정 (PRD 9.6)

알려진 리스크
  • 배포 크기: zip 189MB (onnxruntime.dll 16MB, VC++ DLL 0.7MB 추가) → ffmpeg 공유 DLL 빌드 검토
  • 라이선스 미검토: 동봉한 ffmpeg는 GPL 빌드라 배포 시 소스 제공 의무 검토 필요. VC++ 런타임은 재배포 조건 확인 필요. 제3자 고지 파일 없음
  • 폭 8% 미만의 작은 오탐은 남을 수 있음 (클릭으로 빼기)
  • 얼굴 검출은 CPU만 사용. 강사님 PC 속도 미측정 (번호판 모델 추가 시 GPU(DirectML) 검토)
  • YouTube 변경으로 yt-dlp가 깨질 수 있음. 설치 폴더에 쓰기 권한이 없으면 -U 실패(무시됨)
  • WebView2 CDP를 쓸 수 없어 실제 앱 자동 테스트 수단이 없음
  • 서명 없는 exe라 인터넷·메신저로 받은 zip이면 첫 실행 때 SmartScreen 경고 가능 (로컬 복사 테스트에서는 미발생, 미검증)
  • yt-dlp.exe 백신 오탐 가능성 (미검증)
  • "압축을 풀지 않고 실행하셨습니다" 문구가 실제 화면에 뜨는지는 버튼을 눌러야 해서 미확인 (감지·앱 실행까지만 확인)

13. 참고와 증거 한계

  • 요구사항: docs/PRD.md
  • 코드 기준: main e064c4a, feature/auto-mask ea1c3ac. 69bf6da·d909c94는 internal/tools가 빠져 있어 단독으로는 빌드되지 않습니다.
  • 얼굴 측정은 유사 정답(같은 검출기, 1280px) 기준입니다. NASA 퍼블릭 도메인 영상 2구간과 사용자 신고 영상 1구간만 측정했습니다.
  • Windows 관측은 개발자 PC(1920×1080, 150% 배율, WebView2 153.0.4234.48) 한 대에서만 했습니다. 강사님 PC 환경은 확인하지 않았습니다.
  • 모의 UI 테스트는 Linux 헤드리스 Chromium에서 VP9/WebM 테스트 영상으로 했습니다. H.264 재생과 WebView2 고유 동작은 검증 범위 밖입니다.
  • "사용자 직접 테스트 소감"은 세부 항목 기록 없이 전달된 의견입니다.
