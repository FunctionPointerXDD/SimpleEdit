우선 확인
  • 최신 빌드를 실제 Windows 앱에서 끝까지 실행: 새 1단계, 저장 후 "이전" 시 영상 유지, 단계 전환 끊김, 이름·위치 저장

알려진 리스크
  • 배포 크기: zip 182MB, 압축 해제 435MB (ffmpeg·ffprobe 정적 빌드 각 약 157MB, deno 약 93MB) → 공유 DLL 빌드 검토
  • YouTube 변경으로 yt-dlp가 깨질 수 있음. 설치 폴더에 쓰기 권한이 없으면 -U 실패(무시됨)

  • 서명 없는 exe라 인터넷·메신저로 받은 zip이면 첫 실행 때 SmartScreen 경고 가능 (로컬 복사 테스트에서는 미발생, 미검증)
  • yt-dlp.exe 백신 오탐 가능성 (미검증)
다음 단계
  • 배포 zip을 다른 PC(또는 새 사용자 계정)에서 풀어 실행 (개발 PC 새 폴더에서는 확인함)
  • 강사님 사용성 테스트 2회 연속 성공 (PRD 완료 기준)
  • i5급 PC에서 1080p 1분 저장 2분 이내 측정

12. 참고와 증거 한계

  • 요구사항: docs/PRD.md
  • 코드 기준: 커밋 69bf6da(origin/main)와 그 뒤 scripts/package.sh zip 생성 방식 수정. 이 문서는 그 수정과 함께 커밋됩니다.
